Mostrar datos de varias tablas relacionadas JOIN Solo devuelve las filas que coinciden en ambas tablas.
Que no falte ninguna venta, cliente o producto aunque no tenga datos asociados LEFT JOIN / RIGHT JOIN Las filas sin coincidencia muestran NULL. Verificar la cantidad de filas.
Todos los registros de ambas tablas LEFT JOIN + RIGHT JOIN + UNION MySQL no tiene FULL OUTER JOIN. Ambos SELECT deben tener las mismas columnas.
Total, cantidad o por cada grupo GROUP BY con función de agregación (SUM, COUNT) Las columnas no agregadas del SELECT van en el GROUP BY.
